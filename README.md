# Francis David - Digital Marketing Portfolio

A modern, responsive portfolio website for Francis David — Digital Marketing Strategist.

## 🚀 Features

- **Modern Dark Theme** with gradient accents
- **Fully Responsive** design for all devices
- **Animated UI** with scroll-triggered animations
- **Interactive Elements** — custom cursor, tilt effects, parallax
- **Portfolio Filter** — filter projects by category
- **Testimonials Slider** with auto-play
- **Contact Form** with validation
- **Social Media Links** — Instagram, Facebook, YouTube
- **Counter Animations** for statistics
- **Preloader** with smooth entry
